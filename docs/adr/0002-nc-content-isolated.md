# ADR 0002 — Non-commercial corpus stays isolated

Status: accepted.

Context: the lesson corpus is CC BY-NC 4.0 and the Marble dataset is ODbL/CC BY-SA. The app code is MIT.

Decision: code and content are licensed separately in LICENSING.md; Marble data lives in its own folder with attribution in every payload. The project is described as "free and open-source software with a non-commercial corpus", never as fully open.

Consequences: legal to run and share for free; commercial reuse of lessons is forbidden; share-alike obligations stay inside the Marble folder. An open content tier (CC BY) is being grown beside it.
