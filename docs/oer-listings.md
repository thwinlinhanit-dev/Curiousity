**Short description (200 chars):**
Curiousity is a free, offline-first K–12 learning app with 5,321 interactive STEM lessons, worked examples, checked practice and spaced review. No accounts, ads or tracking. Code MIT; lessons CC BY-NC 4.0.

**Long description:**
Curiousity teaches by taking figures apart. Each lesson pairs a manipulable figure with paced narration, worked examples and practice generated from checked code. A shared progress engine schedules reviews with mastery tracking and save codes — no accounts or cloud sync. It works with the wifi off, on a school phone, and costs nothing to use or host yourself. The 22 subject ladders cover mathematics, science, history, languages, art, music and life skills. Application code is MIT; the imported lesson corpus is CC BY-NC 4.0 with attribution, and a growing CC BY tier is included.
