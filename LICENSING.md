# Licensing

This project contains several kinds of material under different terms. Each part is listed below. Where a part's terms are not yet decided or confirmed, the file says so.

## What applies to what

| Part | Where it lives | Terms | What that means for you |
|---|---|---|---|
| Application code | `src/`, `scripts/`, `public/docs/`, configuration | **Not yet chosen by the maintainer.** The intent is a permissive OSI licence (MIT or Apache-2.0). | Until a `LICENSE` file is added, normal copyright applies: you may read and run the code, but not redistribute or modify it. |
| Lesson corpus | `content/` (fetched at build time from a pinned commit; not stored in the working tree) | CC BY-NC 4.0, © Teddy Rook | Free to use, share and adapt for **non-commercial** purposes, with credit and a link back. Not for commercial use. |
| Standards and misconception data | `content/marble/` | ODbL 1.0 (database), CC BY-SA 4.0 (content), © Generative Spark, Inc. (Marble) | Share-alike applies to this folder. Attribution is included in every data payload. The rest of the project is kept separate from it. |
| Figure kits and maths engine | `public/vendor/` | The Teddy Rook engine. Lesson footers describe it as MIT. | Confirm against the upstream licence file before redistributing. |
| Spanish translations | `content/i18n/es/` | Generated by machine translation (`scripts/translate-es.mjs`) and not reviewed by a person. | Treat as covered by the corpus licence until a reviewer confirms otherwise. |
| Music scores | `content/music/` | Described in the app as public-domain scores. | Confirm the source of each score before reuse. |
| Dataset items | `content/data/` | Each dataset states its own source and licence. | See the Credits and licences dataset in the app, and check each item. |

## What "open" means here, stated precisely

- **The software** will be free to run, copy and modify once the code licence above is chosen and published.
- **The lesson corpus** is free for non-commercial use with credit. It is **not** open content under the Open Definition, because it forbids commercial use.
- **The project as a whole** should therefore be described as *free and open-source software with a non-commercial corpus*. It should not be described as fully open.

## Attribution

When you reuse lessons or data from this project:

- credit **Teddy Rook** for the lesson corpus (CC BY-NC 4.0);
- credit **Marble Skill Taxonomy, © Generative Spark, Inc.** for standards and misconception data, and keep it under ODbL and CC BY-SA;
- link back to the project.

## Open decisions

These need a maintainer decision or an upstream confirmation before this file can be final:

1. Choose the application code licence (MIT or Apache-2.0), add a `LICENSE` file with the copyright holder's name, and update the first row of the table above.
2. Confirm the licence of the vendored Teddy Rook engine against its upstream `LICENSE`.
3. Confirm the public-domain status of each music score.
4. Ask the corpus author whether a CC BY 4.0 subset, or a relicence of original material, is possible.

This file is not legal advice. If you plan commercial use, get advice on the corpus terms first.
