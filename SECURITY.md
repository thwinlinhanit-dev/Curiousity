# Security

This app has no server, no accounts and no third-party analytics. Learner data stays in localStorage.

Report a vulnerability privately to the maintainer rather than opening a public issue. Include the affected version and reproduction steps. We aim to acknowledge within seven days.

Vendored kits under `public/vendor/` come from the upstream corpus; check their licences before redistribution. Do not add scripts from third-party origins — the Content Security Policy is `script-src 'self'`.
