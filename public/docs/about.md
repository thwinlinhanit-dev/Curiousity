# About Curiosity

Curiosity is a free learning app. It teaches by taking figures apart: lessons with interactive figures, worked examples, practice with answer checking, and spaced review.

There are no accounts, no ads and no paid tier. Your progress is saved in this browser. Use **Save code** on the home page to copy it and move it to another device.

## Privacy

Your progress and ideas stay in this browser. Clearing site data erases them, unless you have copied a save code first.

The app loads its scripts and data from the host that serves it. If you ever see a request to a third-party site, please report it as a bug.

## Feedback

The idea box saves to this browser only, unless the site has a feedback server configured.
