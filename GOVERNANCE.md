# Governance

- Decisions happen in public issues and pull requests.
- The roadmap lives in the repo (`public/docs/roadmap.md` and the root planning notes).
- One maintainer currently cuts releases. A release is: update CHANGELOG, tag `vX.Y.Z`, run `npm run build`, attach `dist/` to the release, publish the DOI.
- Bus factor plan: two people should be able to cut a release. Nominate a second maintainer before v1.0.
- Contributors are credited in README, translators in the lesson, reviewers in CHANGELOG.
- Disagreements about content are settled by the content review rubric: factual accuracy, one worked example, a stated common mistake, sources, reading level.
